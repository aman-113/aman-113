## 📌 Featured Projects

### 🎮 PlayDeck
*React · TypeScript · FastAPI · WebSockets · Redux Toolkit*

A real-time multiplayer gaming platform where phones join a shared room and act as **wireless controllers** for a browser-based game. Uses a WebSocket room architecture with per-room broadcast isolation and a plugin system that lazy-loads game/controller pairs. Currently ships with one playable title: **Snake Grid**.

### 🧠 AI-Based Grievance Management System
*React.js · Flask · SQLAlchemy · Whisper · RabbitMQ · Socket.IO*

A microservices-style grievance platform with a JWT-secured API gateway. Heavy ML inference (BART-large-MNLI zero-shot classification, speech-to-text) is separated from lightweight CRUD services. Grievances are **automatically routed to the right committee** using zero-shot NLP, with async notifications.

### 💬 Encrypted Real-Time Chat *(professional work)*
*React Native · Node.js · Express · WebSockets · Cloudinary*

A chat platform with **RSA + AES end-to-end encryption** and Cloudinary-powered media sharing.
